# 📊 Sales Analysis & Forecasting Dashboard

## 🔍 Overview

This project focuses on analyzing sales data to generate meaningful insights and predict future trends. It combines data processing, visualization, and forecasting into a single workflow, helping businesses make data-driven decisions.

## 📁 Dataset

The dataset contains sales-related information such as orders, products, revenue, and customer details. It is used for exploratory data analysis (EDA), cleaning, and building insights.

## 🛠️ Tools & Technologies

* **Python** (Pandas, NumPy, Matplotlib, Seaborn) – Data cleaning & EDA
* **SQL (PostgreSQL/MySQL)** – Data querying & transformation
* **Power BI** – Interactive dashboard creation
* **Gamma** – Presentation generation

## ⚙️ Steps

1. Load dataset using Python
2. Perform data cleaning (handling missing values, duplicates)
3. Conduct EDA to identify trends and patterns
4. Run SQL queries for deeper analysis
5. Build interactive Power BI dashboard
6. Create presentation using Gamma

## 📊 Dashboard

The Power BI dashboard includes:

* Sales trends over time
* Top-performing products
* Customer insights
* Revenue analysis
* Forecasting visuals

## 📈 Results

* Improved understanding of sales performance
* Identification of key business trends
* Data-driven decision support
* Accurate sales forecasting

## ▶️ How to Run

1. Install required Python libraries
2. Load and clean dataset in Python
3. Import data into SQL database
4. Connect Power BI to database
5. Build and explore dashboard
